# Kit DeepSeek — Oncologia Cacoal

Pacote de instruções para trabalhar com DeepSeek no projeto, reduzindo contexto repetido e consumo de tokens.

## Primeiro passo
Copie esta pasta para o repositório.

Depois utilize o “Prompt 1 — Primeiro diagnóstico do repositório” de `docs/PROMPTS_DEEPSEEK.md`.

O primeiro diagnóstico NÃO deve programar. Ele apenas identifica o que já existe e atualiza `docs/DEVELOPMENT_STATUS.md`.

## Regra de ouro
Uma Issue por tarefa e uma conversa principal por Issue.
