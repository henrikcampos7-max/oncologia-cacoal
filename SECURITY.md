# Dados e segurança

Este repositório não deve armazenar informações pessoais ou clínicas identificáveis, incluindo nomes de pacientes, números de carteirinha, documentos, prescrições, datas de atendimento vinculadas a pessoas ou históricos de tratamento.

Também não devem ser versionados planilhas operacionais, bancos de dados, arquivos `.env`, tokens, senhas, chaves privadas ou credenciais de serviços.

Para desenvolvimento e testes:

- use somente dados inteiramente fictícios;
- mantenha revisão humana para decisões clínicas, compras e movimentações de estoque;
- não assuma equivalência entre medicamentos ou apresentações;
- trate alertas e previsões como apoio administrativo, nunca como prescrição;
- realize revisão de segurança antes de qualquer implantação.

Se um dado sensível for adicionado por engano, interrompa a publicação e remova-o também do histórico antes de continuar.
