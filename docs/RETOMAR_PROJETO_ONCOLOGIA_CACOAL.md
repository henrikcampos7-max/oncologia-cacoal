## Sequência segura na retomada

1. Abrir a URL do projeto e conferir o identificador.
2. Confirmar se a conta possui créditos disponíveis, sem realizar compra automática.
3. Anexar `logo_unimed_extraida.png` ao projeto quando o Lovable solicitar o ativo.
4. Enviar o conteúdo combinado de `COMANDO_RETOMADA_LOVABLE_UNIMED.txt`.
5. Criar o repositório local separado `oncologia-cacoal`, somente após verificar que ele ainda não existe.
6. Não alterar os repositórios de terceiros `opensquad` e `agentic-awesome-skills`.
7. Organizar a equipe de agentes para agenda, tratamentos, medicamentos, estoque, lotes, validades, compras, alertas, auditoria e relatórios.
8. Continuar o MVP usando `PROMPT_LOVABLE_MVP_IMPORTACAO.txt`.
9. Revisar visualmente em computador e celular.
10. Não publicar, fazer push ou inserir dados reais sem autorização expressa.
